# Launch the foundation shade gap explorer

Opens an interactive Shiny app that helps beauty product strategy
managers compare a brand's foundation shade range with the market, find
the lightness bands where the brand is thinner than the market, and see
which competitor products lead those bands.

## Usage

``` r
run_app()
```

## Value

Called for its side effect of launching the app.

## Examples

``` r
if (interactive()) {
  run_app()
}
```
